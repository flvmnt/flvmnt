#### What I'm working on

**[pgfence](https://pgfence.com)** - Postgres migration safety CLI that tells you what locks your DDL takes and gives you the safe rewrite. It analyzes ORM migrations (TypeORM, Knex, Sequelize, Prisma, Drizzle), not just raw SQL. Prisma documents pgfence as a [pre-deploy migration safety check](https://www.prisma.io/docs/orm/prisma-client/deployment/deploy-database-changes-with-prisma-migrate#pre-deploy-migration-safety-checks), and pglt lists it in [Related Work](https://github.com/supabase-community/postgres-language-server/blob/main/docs/reference/related_work.md).

More in the works.
