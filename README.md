Also the main suspect behind my 10k+ GitHub contributions over the past year. 🙂

**[pgfence](https://pgfence.com)** — An open-source PostgreSQL migration safety tool that identifies the locks your DDL takes, flags risky changes and suggests safer rewrites. Supports raw SQL and migrations from TypeORM, Knex, Kysely, Sequelize, Drizzle and Prisma Migrate SQL. Available as a CLI, GitHub Action and VS Code extension.

**ProfitLogic** — A closed-source sports-odds collection and analysis pipeline with asynchronous scraping, event and market matching, historical odds storage and personalized Telegram alerts. Built with Python, FastAPI, TimescaleDB and Redis.

**Cadentra Rent** — A closed-source rental-property application connecting tenants and contracts with meter readings, monthly charges and payment tracking. Built with Next.js, NestJS and PostgreSQL.

#### Around the ecosystem

Its [deployment documentation](https://www.prisma.io/docs/orm/v7/prisma-client/deployment/deploy-database-changes-with-prisma-migrate#pre-deploy-migration-safety-checks) also includes pgfence as a pre-deploy migration safety check.
- **Postgres Language Server (pglt)** lists pgfence in [Related Work](https://github.com/supabase-community/postgres-language-server/blob/main/docs/reference/related_work.md) and [credits it as a source for multiple migration safety rules](https://github.com/supabase-community/postgres-language-server/blob/main/docs/reference/rule_sources.md#pgfence).
