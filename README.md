### Hey, I'm Flavius

Full-stack TypeScript developer. Building SaaS. Open to contract work.

#### What I'm working on

**[pgfence](https://pgfence.com)** - Postgres migration safety CLI that shows the locks your DDL takes and suggests safer rewrites. It analyzes raw SQL and migrations from TypeORM, Knex, Kysely, Sequelize, Drizzle, and Prisma Migrate SQL.

More in the works.

#### Around the ecosystem

- [Prisma's pgfence integration guide](https://www.prisma.io/docs/guides/integrations/pgfence) walks through using it with Prisma ORM 7, and its [deployment docs](https://www.prisma.io/docs/orm/v7/prisma-client/deployment/deploy-database-changes-with-prisma-migrate#pre-deploy-migration-safety-checks) include it as a pre-deploy check.
- Postgres Language Server (pglt) lists pgfence in [Related Work](https://github.com/supabase-community/postgres-language-server/blob/main/docs/reference/related_work.md) and [credits pgfence](https://github.com/supabase-community/postgres-language-server/blob/main/docs/reference/rule_sources.md#pgfence) as a source for safety lint rules.
- [awesome-postgres](https://github.com/dhamaniasad/awesome-postgres/blob/master/README.md#cli) lists pgfence among its CLI tools.
